# solar-orbiter-flare-statistics

Statistical exploration of Solar Orbiter STIX flare observations. Summer internship, June to August 2026. 

## Goal 
Work towards a picture of what a typical STIX flare looks like, using the STIX science flare list and quicklook lightcurves. 

## Structure 
- notebooks/ analysis notebooks 
- figures/ saved plots 
- data/ local data (flare list), not tracked by git 
- docs/ weekly reports 

## Data 

- STIX science flare list: https://github.com/hayesla/stix_flarelist_science 
- STIX quicklook lightcurves via stixpy 
- GOES XRS lightcurves via sunpy
